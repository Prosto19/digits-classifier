# Digit Classifier — Распознавание рукописных цифр

Мой первый проект в области машинного обучения (Machine Learning).

 О проекте

Программа распознаёт рукописные цифры от 0 до 9 с помощью алгоритма **K-Nearest Neighbors (KNN)**.

Для обучения и тестирования используется датасет `load_digits` из библиотеки Scikit-learn, содержащий 1797 изображений размером 8×8 пикселей.

## Как работает модель

1. Загружаем изображения цифр и правильные ответы.
2. Разделяем данные на обучающую (80%) и тестовую (20%) выборки.
3. Используем KNN с одним ближайшим соседом (`k=1`).
4. Для определения расстояния между изображениями применяется Manhattan Distance.
5. Модель предсказывает цифру на новых изображениях.

 🛠 Технологии

- Matplotlib
- KNN (K-Nearest Neighbors)
